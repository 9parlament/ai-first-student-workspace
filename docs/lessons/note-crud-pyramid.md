# Занятие: CRUD одной заметки × пирамида

Живой отчёт. Обновлять **в конце фазы**. PDF и PR — только по OK человека.

## Цель

Полноценный CRUD **одной** заметки на пользователя (без списка).  
«100% пирамиды» = каждый сценарий на своём `@Layer` (`test-pyramid`).  
Не 100% строк JaCoCo. Не e2e на весь CRUD. Slice (`smoke` / `screenshot` / `mock`) ≠ слой.

Продукт на старте занятия: логин/регистрация + health/items. Заметку **ещё не реализуем** (фаза 0).

## Вывод: зачем skills / rules / RAG / ADR

Черновик (закрыть в конце занятия, когда пройдены ярусы):

| Слой | Роль на этом занятии |
|------|----------------------|
| **Skill** | Как сделать задачу: `qa-make-full-pyramid` = один ярус за вызов + STOP; api/e2e пишет `qa-write-test`; карту не подменять `qa-coverage-audit`. |
| **Rule** | Что нельзя: нет commit без OK; один task = один `@Layer`; URL не в Java; delete на prod не без OK. |
| **RAG** | Факты на 2–4 файла: команды яруса, slice≠слой, стенды, JaCoCo ≠ пирамида. |
| **ADR** | Почему надолго: одна заметка, не список; screenshot не слой (005); delete не на prod по умолчанию (006). |

Без этой связки агент либо пишет e2e на весь CRUD, либо путает «100%» с JaCoCo, либо молча выбирает список заметок в чате.
